# Dinesh Lakhi — Python Developer Portfolio

A responsive, static portfolio website built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Deploy free with GitHub Pages
1. Create a GitHub repository named `dinesh-lakhi-portfolio`.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. The URL will be shown in Settings → Pages.

## Personalisation before publishing
- Add a professional headshot if desired.
- Add verified project names, exact technology stacks, and repository links when available.
- Confirm the exact degree title against the degree certificate.
- Add a downloadable resume only if you want it publicly accessible.

The content intentionally avoids inventing client work, GitHub repositories, or project technologies.
